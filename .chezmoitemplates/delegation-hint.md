## Delegation

Delegate bounded work before implementing a task with independent parts, repetitive work, or an independent review.
The user authorizes native subagents and installed Codex, Cursor, and Claude workers.
Keep design, judgment, and final acceptance with the lead.
Read the delegate skill or `~/.agents/DELEGATION.md`; check live capabilities and capacity rather than CLI version numbers.
Unknown quota is uncertainty, not a ban on delegation; use a bounded authorized worker when appropriate.
If `AGENT_DELEGATION_DEPTH=1` or the assignment starts with `DELEGATED_WORKER`, complete only that assignment yourself.
